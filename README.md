# 南京大学课表导出插件

用于南京大学本科教务系统的浏览器插件，支持读取当前页，或将“全部课程”的当前筛选结果自动翻页汇总，下载为 JSON。导出的内容仅保存在本机，不自动上传。

当前插件版本：v0.21.0。

## 适用范围

目前仅适配南京大学本科教务系统的“全部课程”（全校课程表）和“我的课表”列表，支持校内入口及南大 atrust 对应入口。暂不支持其他学校、研究生教务或选课系统。

“全部课程”指当前账号、所选学期及筛选条件下可见的课程，不代表所有学期或所有权限范围的课程。

## 安装

适用于 Chrome 或 Edge 电脑版。

1. 下载本仓库（Code → Download ZIP），完整解压到固定目录。
2. 浏览器地址栏输入 `chrome://extensions` 或 `edge://extensions`。
3. 开启“开发者模式”，点击“加载已解压的扩展程序”或“加载解压缩的扩展”。
4. 选择直接包含 `manifest.json` 的文件夹，不要选择 ZIP 或上一级目录。
5. 将“蹭课网 · 南大课表导出（试验版）”固定到浏览器工具栏。

更新时替换插件文件，在扩展管理页点击“重新加载”。

## 快速使用（v0.21.0）

1. 打开插件，点击“打开南大全部课程”；校外访问入口在“更多选项”。具体入口可能先跳转学校登录页，请自行登录并选择“学生组”，进入“全部课程”。
2. 选择学期和筛选条件，点击学校页面搜索，回到第一页，再打开插件。
3. 插件自动检查当前页面，显示已识别的学期和当前页条数；确认无误后点击“导出当前筛选的全部课程”。检查失败会提示下一步，不会开始翻页。
4. 进度在学校页面右上角展示，保持页面打开。完整导出自动发起JSON下载；若浏览器未下载，点击面板中的下载按钮。部分结果仍需手动下载并核对。
5. 点击“打开蹭课网导入”，在网页中选择刚下载的JSON、预览并确认。插件不自动把课表传给网页。

单页导出、手动学期与诊断信息收在“更多选项”。不需要另装独立程序，安装过程仍使用浏览器开发者模式。

## 导出全部课程

1. 自行登录南大教务平台，切换到 **“学生组”（不是“本科组”）**。
2. 进入 **“全部课程”**，选择学期、校区等筛选条件并点击搜索，确认显示课程列表。
3. 回到结果第一页，打开插件。若学期无法自动识别，在插件中填写完整学期，例如“2026-2027学年 第1学期”。
4. 点击 **“导出当前筛选的全部课程”**。页面中会出现进度面板；保持学校页面打开，不刷新或改变筛选条件。
5. 完成后按面板提示下载 JSON。若停止、超时或数量不符，导出文件会标记为部分结果，不能当作完整数据。

自动翻页间隔至少1.5秒，最多20000条/2000页。只需要当前页时，点击“仅导出当前页”。导出个人已选课程时，使用“我的课表”列表。

## 数据与权限

- 读取课程号、教学班名称、教师、校区、院系、学期、时间地点等课表字段；不读取密码、Cookie或学生名单。
- 扩展仅申请 `activeTab` 和 `scripting` 权限，由用户点击后在支持的课表页面读取内容。自动翻页会通过学校页面加载下一页。
- 下载文件使用 `cengke-nju-visible-v1` 格式。插件保留原始排课信息，不负责转换为日历日期或判断旁听许可。
- 本仓库提供插件、格式说明及虚构示例，不含真实课表。请自行保管导出文件，不要将账号信息或真实课表提交到仓库或 Issues。
- 本插件为独立试验工具，非南京大学官方应用，未获得学校官方兼容性认证。

## 常见问题

- **找不到 manifest.json**：先解压，选择直接包含该文件的目录。
- **提示页面不支持或找不到列表**：切到学校课表标签页，确认角色、入口和课程列表，等待搜索结果加载。
- **分页识别失败或导出中断**：按照面板提示操作，保留部分结果；重新导出前返回第一页。
- **反馈问题**：提供插件版本、错误文字和不含课程内容的结构诊断即可，不提供密码、Cookie或整页登录数据。

卸载：在浏览器扩展管理页点击“移除”。卸载插件不会自动删除已下载的 JSON。


## 课表与校历文件格式

- [课程表 JSON 格式要求](docs/json-formats/课程表JSON格式要求.txt)：必填、可空、可选字段及排课文本规则。
- [校历 JSON 格式要求](docs/json-formats/校历JSON格式要求.txt)：学期、第一教学周周一及节次作息的格式与校验规则。
- [课程表示例](docs/json-formats/课程表示例.json)：7个纯虚构教学班，用于说明格式。
- [校历模板](docs/json-formats/校历模板.json)：沿用现有南大公开校历配置，实际使用前请核对学期和校区作息。

插件只负责导出课表 JSON，不读取或导入校历。校历与日期换算说明用于配套的蹭课网本地版；本仓库不包含课表网页程序。安装扩展时仍选择本仓库根目录（直接包含 manifest.json），不选择 docs 文件夹。
