课程表 JSON 格式要求
格式版本：cengke-nju-visible-v1
适用实现：蹭课网独立本地版 v0.29.3；现有南大插件 v0.20.4

一、用途及文件要求
用于网页“课表 JSON”入口，不是校历文件，也不是包含收藏备注的备份文件。
当前适配南京大学本科教务课程列表。文件为 UTF-8 标准 JSON，对象字段名区分大小写，使用英文双引号，不允许注释、尾随逗号。
网页文件限制：不超过 30 × 1024 × 1024 字节；rows 包含1–20000个教学班；日期展开后最多200000条排课。
同一文件只能包含一个学期。课程号可能有前导零，必须用字符串，例如 "00001234"。

二、文件顶层字段
必填：
format：字符串，固定值 "cengke-nju-visible-v1"。
term：非空字符串，最多100个长度单位，例如 "2026-2027学年 第1学期"。
rows：非空数组，每个元素为一个教学班对象，具体见第三节。

可选，建议按下列约定填写：
source：字符串。全校查询填 "schoolwide"；个人课表可以省略，省略按个人来源处理。
scope：字符串。全部筛选结果填 "all-filtered-pages"；中断/未完成分页填 "partial-pages"；当前页可以省略。不是“全校所有学期”覆盖保证。
complete：布尔值 true/false。未完成必须填写false，不使用字符串 "false"。
isMock：布尔值。虚构示例填true，真实文件省略或false。
expectedRows：整数，记录筛选结果预计总行数。
pages：整数，记录已收集页数。
reason：字符串，说明导出中断原因。
上述可选元数据并非全部做严格类型校验，不应把“当前未拒绝”视为允许任意值；统计字段不替代对实际rows的核对。

三、rows 中每个教学班的字段
【必须有字段，且内容不能为空】
name：课程/教学班名称，字符串；不能是空串或全空格；最多4000个长度单位。

【必须有字段，但允许空字符串 ""】
code：课程号，字符串，最多4000个长度单位。
teacher：教师名称，字符串，最多4000个长度单位。
schedule：原始时间地点文本，字符串，最多4000个长度单位。
这些字段即使未知也必须保留键并填 ""，不能省略、填null或数字。

【可选】
campus：校区字符串，最多300个长度单位，缺失时展示为未标注校区。
department：开课单位字符串，最多300个长度单位。
term：行级学期字符串，最多300个长度单位；省略或空串时使用顶层学期。有值时须与顶层term相同（行级比较只忽略空格，不自动等同不同学期写法）。
当前实现兼容上述三个可选字段为null，但生成文件时建议省略或使用空字符串。

【不是必填且当前不会直接导入】
category：课程类别。类别不应要求用户填写。
tags：人工标签。当前页面根据课程名、开课单位生成规则标签，不读取此字段作为标签结果。
其他未知字段不会自动成为页面可用字段。不要在文件中加入密码、Cookie、学生名单等无关信息。

长度说明：当前实现使用 JavaScript String.length；常见汉字通常计1，部分表情符号可能计2，不等同严格的视觉字数。

四、schedule 排课写法
推荐结构：星期 + 节次 + 周次 + 地点。
示例：
周一 1-2节 1-16周 测试教室A
周二 3-4节 1-16周(单) 测试教室B
周三 5-6节 2-16周(双) 测试教室C
周四 1-2节 1,3,5周 测试教室D
周一 1-2节 1-8周 测试教室A；周三 3-4节 9-16周 测试教室B

星期支持周一至周日（或星期一等），节次1–20，周次1–30；节次必须有对应的校历作息。完整多段安排用分号分隔，每段都写星期、节次、周次。
地点可以为空，但会产生待人工补充提示。
空字符串：保留课程，归入原始信息缺失，不生成时间匹配结果。
纯“自由时间”：保留课程，在自由时间目录展示，不参加具体时段匹配。
非空但无法识别、缺少所需节次作息、自由时间与固定安排混合：保留课程，进入解析待核查；不会凭空猜时间，也不会保留该门课程仅解析成功的一部分安排。

五、完整最小示例（虚构）
{
  "format": "cengke-nju-visible-v1",
  "term": "2026-2027学年 第1学期",
  "isMock": true,
  "rows": [
    {
      "code": "DEMO01",
      "name": "模拟课程",
      "teacher": "",
      "schedule": "周一 1-2节 1-3周 测试教室A"
    }
  ]
}

六、导入行为与注意事项
1. 先选择课表，再选择匹配校历或核对自动填入的日期作息。
2. 字段结构错误、必填字段缺失、空名称、混合学期会拒绝整份文件；当前课表不被覆盖。
3. 正常预览也不会立即替换原课表，须点击确认导入。
4. 同一身份的完全重复行会去重；不同教学班可以使用相同课程号，不要仅按课程号自行合并。
5. 确认导入替换当前数据集。只有课程标识仍匹配的收藏、备注可保留；修改原排课文本等内容可能改变标识。
6. 当前不自动处理节假日、临时调课或考试安排。课表可见不代表允许旁听。
7. cengke-local-backup-v1 文件请走“恢复备份”，不要从课表入口导入。

同目录“课程表示例.json”为7行纯虚构示例，覆盖固定、自由时间、缺失及解析待核查情形。
